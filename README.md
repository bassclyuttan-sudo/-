# Claude 活用レッスン資料（肉の輸入業務向け）

海外から肉を仕入れている英語話者（日本語は少し話せる）に、Claude / Claude Code の活用方法を遠隔で教えるための資料一式です。

## ファイル一覧

| ファイル | 用途 | 言語 | いつ使う |
|---|---|---|---|
| [`01_hearing-sheet_EN.md`](01_hearing-sheet_EN.md) | 事前ヒアリングシート | 英語 | **最初にメールで送る** |
| [`02_session-agenda_JP-EN.md`](02_session-agenda_JP-EN.md) | セットアップ手順、当日アジェンダ、早見表 | 日英併記 | セットアップ通話と本番 |
| [`03_demo-prompts.md`](03_demo-prompts.md) | デモ用プロンプト集（5本）と講師メモ | 英語プロンプト＋日本語解説 | 本番前のリハーサルと本番 |
| [`sample-data/`](sample-data/) | ダミーの発注書（xlsx）、請求書（pdf）、パッキングリスト（pdf） | 英語 | リハーサル用。相手のサンプルがなければ本番でも使える |
| [`scripts/make_sample_data.py`](scripts/make_sample_data.py) | ダミーデータの生成スクリプト | - | ダミーデータを作り直すとき |

## 進め方

1. **ヒアリングシートを送る**：回答とサンプルファイルを返してもらう
2. **リハーサル**：`sample-data/` と `03_demo-prompts.md` の Demo 1〜2 を自分で一度試す
3. **セットアップ通話（15分）**：`02` の Part A。ここで Claude が動く状態にしておく
4. **本番（60〜90分）**：`02` の Part B〜D。Demo 1 → Demo 2 の順に進め、相手に自分で操作してもらう
5. **フォロー（1〜2週間後に30分）**：Demo 3〜5 から、相手の困りごとに合うものを選ぶ

## 注意

- `sample-data/` の会社名、数字、書類はすべて架空です。
- 相手の実データを使うときは、社内ルールを確認し、必要に応じて金額や取引先名を伏せてもらってください。
